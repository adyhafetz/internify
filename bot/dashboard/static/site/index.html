Internify

Internify is a personal assistant that tailors a 1-page resume to a job posting. You send a job link to a private Telegram bot, and it writes a resume using only the experience you have saved yourself, then sends you the PDF.

Open the live dashboard (private, needs a key)

What it does with Google

If you connect your own Google account, Internify saves each finished resume PDF to a Google Drive folder you choose and adds one row per application to a Google Sheet you choose, so you can keep track of where you have applied.

Internify is open source and runs on the owner's own computer or server. It is a personal tool and is not offered to the public.

Source code and contact: github.com/adyhafetz/internify
